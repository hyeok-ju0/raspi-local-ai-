- 외부에서 폰/노트북/태블릿으로 집 라즈베리파이 AI 접속

## 하드웨어 설계 (확정)

### 배터리 시스템 — 최종 확정 (Plan A)
> 초기 계획이었던 LiPo 2000mAh/3000mAh + IP5305T/IP5306 조합은 여러 차례
> 재검토를 거쳐 아래로 최종 확정되었습니다.

- LiPo 605080 (내장 보호회로) + FM5324HJ1 자체 배선
- CC1/CC2 5.1kΩ 풀다운 저항 완료
- 전원 종류 기반 모드 판별: `/proc/device-tree/chosen/power/max_current`
  값이 0xbb8(3A)이면 휴대 모드, 0x1388(5A)이면 거치 모드로 부팅 시 자동 판별
  (실시간 저전압 신호 감지보다 신뢰도가 높음을 확인)
- 스로틀링 실측 `0x0` 완전 유지 확인 → **99% 확정**

### 케이스 전략 (진행 중)
- Fusion 360 재작업 중, Printables "snap fit" 커뮤니티 모델 기반
- 완전 개방형 통풍 구조로 변경 (기존 측면 통풍구 방식에서 전환)
- `bottom:1` 컴포넌트 스케치부터 재개 필요
- 절연 테이프/시트를 디스플레이·배터리 모듈·Pi5 사이 어디에 배치할지는 미결정

### 킬 스위치 / LED 방식 (확정)
- 별도 물리 토글 스위치는 **불필요로 결론** — 전원 케이블 탈착 자체가
  On/Off 겸 모드 전환 트리거 역할을 함
- 무선 차단은 소프트웨어(rfkill) 방식: `killon`(차단)/`killoff`(허용)
- RGB LED 3개로 분리 확정 (색상 중복 문제 해결):
  - LED1: 무선 상태 (파랑=ON, 빨강=OFF, 녹색=거치모드+외부접속중)
  - LED2: 온도 경고 (주황=70~80도, 빨강=80도+)
  - LED3: 저전압 경고 (빨강, 평상시 색상 미정)
- 물리 장착은 아직 미착수

> ⚠️ **중요 제약**: 휴대 모드 충전 모듈(FM5324HJ1)에 5A 어댑터를 추가
> 연결하면 저전압 경고 및 강제 재부팅이 발생합니다. 모드 전환은 반드시
> 전원을 완전히 차단한 후에만 진행해야 합니다.

### 부차적 위협 — 재평가됨 (2026-08)
> ⚠️ **번복된 판단**: 초기에는 "분실/도난 시 디스크 암호화는 불편함 대비
> 효용 낮음 → Tailscale 원격 차단으로 충분"이라고 판단했습니다. 하지만
> RAG를 도입하면서 개인 노트·수업자료가 한 폴더에 집중되는 지점이 생겨,
> 이 판단을 **번복**했습니다. 현재는 gocryptfs 기반 **RAG 폴더 암호화**와
> **휴대 모드 화면/세션 잠금**을 함께 채택했습니다(암호화만으로는 "기기가
> 켜진 채로 분실"되는 가장 흔한 시나리오를 막지 못하기 때문에 반드시 둘을
> 함께 구현해야 함).
- AI 로그 평문 저장 → 초기엔 "수동 정리"에 의존했으나, **로그 자동
  삭제/만료 관리** 기능으로 자동화 확정(구현 예정)
- 같은 Wi-Fi 다른 기기 → 집 Wi-Fi 비밀번호 강도로 충분 (변경 없음)

## 성능 실측 결과

### 2026-06-20 (Qwen3 8B, 최초 측정)
| 항목 | 수치 |
|---|---|
| eval rate (8B) | 2.10~2.29 tokens/s |
| 추론 중 최고 온도 | 64.2도 |
| 대기 온도 | 50~56도 |
| RAM 점유 (8B) | 6.3GB / 7.9GB |

> ⚠️ **위 수치는 2026-08 기준으로는 참고용입니다.** 이후 Nextcloud+Redis+
> MariaDB 등 다른 백그라운드 서비스가 추가되면서 실제 여유 메모리는 이보다
> 훨씬 적어진 상태였습니다(2026-08 OOM 트러블슈팅에서 확인, 여유 27MB까지
> 떨어진 사례 있음). Qwen3 8B에 대한 최신 재측정은 아직 미실시입니다.

### 2026-08 발견: 파라미터 수와 실제 메모리 사용량은 다르다
Gemma 4 E2B의 "E2B"는 실제 총 파라미터가 아니라 유효 연산량 기준 명칭으로,
실제 총 파라미터는 5.1B이며 vision/audio 등 멀티모달 capability를 텍스트
전용 사용에도 상시 포함합니다. 오히려 파라미터가 더 큰 Qwen3 8B(8.2B,
텍스트 전용)가 더 안정적으로 구동되었습니다. **파라미터 수만으로 메모리
사용량을 예측하면 안 된다**는 교훈을 얻었습니다.
